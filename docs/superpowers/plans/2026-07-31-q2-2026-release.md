# Q2 2026 PSGC Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release `2026.2.0` with reproducible PSGC data as of 30 June 2026 and focused coverage for every cumulative Q1/Q2 change.

**Architecture:** Drive every retained data artifact through the existing XLSX → JSON/CSV → compressed TypeScript pipeline. Keep release regressions in the existing integrity suite and prove generation determinism with one CI command.

**Tech Stack:** Bun, TypeScript, XLSX, Vitest, npm, GitHub Actions

## Global Constraints

- Use `assets/PSGC-2Q-2026-Publication-Datafile.xlsx` as the sole workbook.
- Publish one cumulative version `2026.2.0`; do not create a Q1 package.
- Keep all existing public APIs and data types unchanged.
- Retain 18 regions, 82 provinces, 1,656 combined municipality/city/submunicipality records, and 42,010 barangays.
